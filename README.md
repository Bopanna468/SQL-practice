OUTER JOINS : USED TO OBTAIN MATCHED RECORDS AND UNMATCHED RECORDS . 
1.LEFT OUTER JOIN: USED TO OBTAIN MATCHED RECORDS ALONG UNMATCHED RECORDS OF LEFT TABLE . 
SYNTAX : SELECT COLOMN-NAME 
FROM TABLE 1 LEFT OUTER JOIN TABLE 2 
ON TABLE 1.COL-NAME=TABLE 2 COL-NAME; 
2.RIGHT OUTER JOIN : USED TO OBTAIN MATCHED RECORDS AND UNMATCHED RECORDS OF RIGHT 
TABLE .  
SYNTAX: SELECT COLOMN-NAME 
FROM TABLE 1 RIGHT OUTER JOIN TABLE 2 
ON TABLE 1.COL-NAME=TABLE 2 COL-NAME;
